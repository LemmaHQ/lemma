# AGENTS.md — Agent Notes

[English](AGENTS.md) | 中文

Agent Note 实际上就是由 Agent 撰写的 RFC：长期保存的提案与决策记录，保留理由、备选方案、后果与必需的验证。遵循[文档标准](../../docs/AGENTS.zh.md)与 [Agent Note 规则](README.zh.md)。

**每篇新的 Agent Note 都要触发一次取代检查。** 在有效目录树中搜索覆盖同一决策或机制的旧 note，使用 `.agents/skills/lemma-archive-agent-notes/SKILL.md` 判定完全取代或部分取代，并在同一个 PR 中归档所有符合条件的已实现文件对。部分取代的 note 保持有效并互相链接。

`archived/` 下的文件是冻结的历史快照：绝不编辑它们，也不把它们当作现行依据。
