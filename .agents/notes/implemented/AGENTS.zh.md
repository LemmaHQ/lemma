## 让已实现的 Agent Note 与实际落地的内容保持同步

在修改路径、符号、默认值与机制的同一次改动中，同步更新 note 中的对应内容。原地改写过时的事实；不要追加变更历史。

已落地的 note 不太可能再指导未来工作时，通过 `.agents/skills/lemma-archive-agent-notes/SKILL.md` 归档其完整的文件对，而不是继续维护它。

### 这并不允许改写*决策*本身

原地更新事实层面的实现情况。推翻决策或其理由需要一篇新的 Agent Note 并互相链接；被完全取代的旧 note 只能按 [Agent Note 规则](../README.zh.md#什么时候写)中的合并规则删除。
