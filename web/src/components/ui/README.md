# Shared UI components

English | [中文](README.zh.md)

## Summary

`web/src/components/ui/` holds the shared controls of the web client: shadcn/ui components built on Radix primitives, styled with the semantic Tailwind utilities from [`design/tokens.json`](../../../../design/tokens.json). Feature code imports them from `@/components/ui/<name>` and combines extra classes through `cn()` from `@/lib/utils`. The components hold no user-facing copy; callers pass translated text. Styling rules are in [Web styling](../../../../docs/web-styling.md).

## Component catalog

| `toggle-group`  | `ToggleGroup`, `ToggleGroupItem`                                                                                                                                                                                                                                                                                                                        | Row of toggles with single or multiple selection, sharing the `toggle` variants; `spacing` 0 joins the items.                                                                                                                                                                                |
| `tooltip`       | `TooltipProvider`, `Tooltip`, `TooltipTrigger`, `TooltipContent`                                                                                                                                                                                                                                                                                        | Short label for an icon-only control, shown on hover and keyboard focus. One `TooltipProvider` in `App` sets the shared delay. In the desktop shell, `TooltipContent` keeps clear of the titlebar.                                                                                           |

Three pairs are easy to confuse:

- **`Tabs` against `ToggleGroup`.** `Tabs` switches which panel is shown and owns the panels through `TabsContent`. `ToggleGroup` sets a value, such as the theme preference, and owns no panels.
- **`AlertDialog` against a toast.** `AlertDialog` asks before an action and blocks until the user answers. A toast reports the outcome of an action after it ran and blocks nothing.
- **`Tooltip` against `title`.** `Tooltip` shows on keyboard focus and follows the theme; the `title` attribute does neither. Icon-only buttons use `Tooltip` plus an `aria-label`.

## Adding a component

Add shadcn components with the CLI from `web/`: `npx shadcn add <name>`. Decline overwriting existing files. [`components.json`](../../../components.json) sets `tailwind.config` to an empty string, which selects the Tailwind v4 templates. Then align the generated file with the existing components:

- import `cn` from `@/lib/utils` and the primitive from its `@radix-ui/react-<name>` package, and remove the `radix-ui` and `cn` packages if the CLI added them;
- read the theme from the `dark` class on `<html>` instead of `next-themes`;
- format with Prettier;
- add the component to the catalog above.
