# 事故复盘

[English](README.md) | 中文

事故记录：一个 bug 到达了它不该到达的地方（真实用户、已合并的 PR、一次发布），值得关注的是*我们的流程为什么放它过去*，而不只是那一行修复。

事故复盘不是 [Agent Note](../../.agents/notes/README.zh.md)（后者记录经过深思的设计决策及被否决的备选方案，或提出未来的工作）。它是对一次失败的回顾性记录：什么坏了、背后的机制、为什么每一道安全网都没有拦住它，以及新增了哪些具体的防护措施，让同类 bug 下次能明显地暴露出来。

当一个 bug 同时满足以下条件时写复盘：**隐蔽**（机制不明显，细心的工程师也要费一番功夫才能重新推导出来）、**系统性**（它逃逸的原因是测试、工具或约定上的缺口，而不是一次性的笔误）、**重新发现代价高**（它耗费了真实的调试时间，再来一次还会耗费）。链接这次复盘所促成的防护措施（测试、`AGENTS.md` 规则、Agent Note）。

每篇复盘以**执行摘要**开头：一段简短的文字，让忙碌的读者三十秒内读完——什么坏了、用平实的话说根因是什么、它为什么逃逸、长期的教训是什么——之后才是详细的 Summary / Timeline / Root cause / Guardrails 各节。

文件按撰写顺序编号，命名为 `0001-topic.md`，并各自带有 `0001-topic.zh.md` 对应文件。本 README 用一张 `| # | Title |` 表格索引每一篇复盘，并链接到各篇。
