# 双语文档

[English](README.md) | 中文

Lemma 的文档以英文与简体中文两种语言维护。本页定义配对契约及其适用范围。

## 配对契约

- **两种语言具有同等效力。** 文档可以先用任一语言写成，再据此翻译出对应版本。两个文件表述相同的内容。
- **一对文件是两个同级文件。** 英文 `foo.md` 与中文 `foo.zh.md` 位于同一目录。修改其中一侧的提交同时更新另一侧。
- **语言切换行。** H1 的下一行在英文文件中为 `English | [中文](foo.zh.md)`，在中文文件中为 `[English](foo.md) | 中文`。
- **结构与对应文件一致。** 标题层级与顺序、列表类型与条目数、表格行列数以及链接目标一一对应；代码块逐字节相同。中文文件中指向已配对文档的链接指向其 `.zh.md` 一侧。

## 范围与例外

**范围**：所有维护中的 Markdown 文档，包括 `README.md` 与 `AGENTS.md` 文件。

**例外**（仅英文，因为工具会原样读取它们）：

- `SKILL.md` 文件及各 skill 下的参考资料。
- `DESIGN.md`，即生成设计 token 的数据源。
- 生成文件。
