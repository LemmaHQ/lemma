# Lemma 圆角标准

[English](ui-radius.md) | 中文

## 概要

按组件角色选择圆角，并让嵌套填充、悬停状态和边框与外层容器对齐。本标准适用于 Web 客户端和桌面端渲染层。

<a id="scope"></a>
## 范围与权威来源

本文定义 `web/` 的圆角刻度及组件规则；[Web UI 样式参考](web-styling.zh.md)定义总体的样式归属。取值位于 [`design/tokens.json`](../design/tokens.json) 的 `radius` 分组，由生成器转换为 `rounded-*` 工具类。修改取值在那里进行；规则变化时同时更新本标准的两个语言版本。

<a id="radius-scale"></a>
## 选择圆角

先确定组件角色。高度、宽度、标签长度和换行都不会让圆角变大：同一角色的更高实例保持该角色的圆角。

| 角色 | 成员 | 圆角 | 工具类 |
|---|---|---|---|
| 小细节 | 行内代码、侧边栏行内操作按钮、菜单项与选择项 | 4px | `rounded-xs` |
| 面板内的嵌入块 | 工具调用的参数块与输出块 | 6px | `rounded-sm` |
| 控件或行 | 按钮、输入框、选择器、工具提示、菜单、会话行与设置行、代码块、工具面板 | 8px | `rounded-md` |
| 窗格或独立外框 | 页面画布面板、确认对话框、标签页轨道、新建对话按钮、侧边栏展开按钮 | 12px | `rounded-lg` |
| 内容卡片 | 卡片、用户气泡、输入框面板 | 16px | `rounded-xl` |
| 保留 | 落地页横幅 | 24px | `rounded-xxl` |
| 圆形或胶囊 | 头像、开关、圆形图标按钮（发送、停止）、状态点 | 9999px | `rounded-full` |

生成器还会输出等于 12px 一档的 `--radius`，即 shadcn 的基础变量。

<a id="shapes"></a>
## 复用 token，保留有意的形状

新增功能自有的几何形状之前，先复用 `web/src/components/ui/` 中的控件。填充、描边、幽灵、加载和禁用变体保持同一圆角；悬停、按下、选中和聚焦状态不改变圆角。

使用具名工具类，不写 `rounded-[10px]` 这类任意值。流式光标、工具提示箭头等绘制细节可以保留自己的小圆角；这不构成给周围控件使用任意圆角的理由。

圆形和胶囊只用于上表列出的成员。矮小的矩形按钮不会因为矮就变成胶囊。

<a id="nested-hover"></a>
## 嵌套几何与悬停

选择子元素圆角前，先判断属于哪种排列：

| 排列 | 规则 | 示例 |
|---|---|---|
| 同心内嵌 | 内圆角 = 外圆角 − 内边距，向下取到最近的一档 | 菜单为 8px、内边距 4px，菜单项为 4px；12px 的标签页轨道内嵌 3px，触发器为 8px |
| 贴住外层边缘的填充 | 外层持有圆角，并用 `overflow-hidden` 裁切填充；填充本身不设圆角 | 代码块的标题条 |
| 另一个表面内的独立表面 | 子元素使用自己角色的圆角 | 消息中的代码块、面板中的工具调用块 |

单个可点击表面在自身上绘制悬停，使用自己的圆角。悬停填充不是可点击元素本身时，与可见外层使用同一圆角，避免填充与边框之间露出月牙形缝隙。

<a id="verification"></a>
## 应用与验证

1. 连同共享原语、浮层和同级变体一起检查组件。替换取值之前先划分角色；同一个旧圆角并不处处对应同一个新 token。
2. 有共享所有者时先改共享所有者，再对齐子元素圆角、裁切和状态样式。独立的子表面保持自己的角色。
3. 在亮色和暗色主题下，对比正常、悬停、选中、禁用和键盘聚焦状态中渲染出的圆角、填充和边框。
